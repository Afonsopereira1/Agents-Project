class ResourceStatus(enum.Enum):

Estados do ciclo de um recurso móvel, da disponibilidade ao regresso.

Attributes: AVAILABLE: Livre para receber uma missão. RESERVED: Reservado para uma missão que ainda não começou. MOVING: A deslocar-se para o alvo. VERIFYING: A inspecionar o alvo. RETURNING: A regressar à base. UNAVAILABLE: Fora de serviço (por exemplo, sem energia).

AVAILABLE = <ResourceStatus.AVAILABLE: 'available'>
RESERVED = <ResourceStatus.RESERVED: 'reserved'>
MOVING = <ResourceStatus.MOVING: 'moving'>
VERIFYING = <ResourceStatus.VERIFYING: 'verifying'>
RETURNING = <ResourceStatus.RETURNING: 'returning'>
UNAVAILABLE = <ResourceStatus.UNAVAILABLE: 'unavailable'>
@dataclass(frozen=True)
class ResourceState:

Estado imutável de um recurso; available acompanha sempre status.

Attributes: resource_id (str): Identificador do recurso. resource_type (str): Tipo de recurso (ex.: drone, vehicle). position (Position): Célula atual. available (bool): True só quando status é AVAILABLE. autonomy_percent (float | None): Energia restante, em % de 0 a 100; None se desconhecida. status (ResourceStatus | None): Estado do ciclo; se omitido, é deduzido de available.

def change_status(self, new_status: ResourceStatus):

Devolver uma cópia no novo estado, com available recalculado.

Args: new_status (ResourceStatus): Estado pedido.

Returns: ResourceState: Nova instância no estado pedido; a atual não muda.

Raises: TypeError: Se o estado não for ResourceStatus. ValueError: Se a transição não for permitida a partir do estado atual.

class MissionStatus(enum.Enum):

Estados possíveis de uma missão.

Attributes: PROPOSED: Missão criada, à espera de um recurso. RESERVED: Atribuída a um recurso, mas ainda não iniciada. RUNNING: Em execução. DONE: Concluída com um resultado (confirmed, not_confirmed ou inconclusive). FAILED: Terminou com resultado failed.

PROPOSED = <MissionStatus.PROPOSED: 'proposed'>
RESERVED = <MissionStatus.RESERVED: 'reserved'>
RUNNING = <MissionStatus.RUNNING: 'running'>
DONE = <MissionStatus.DONE: 'done'>
FAILED = <MissionStatus.FAILED: 'failed'>
@dataclass(frozen=True)
class Mission:

Missão (verificação por patrulha ou resposta por ranger) criada em resposta a uma ocorrência.

Attributes: mission_id (str): Identificador único da missão. incident_id (str): Identificador da ocorrência associada. task (str): Tarefa a executar. target (Position): Posição de destino. required_capability (str): Capacidade necessária para a executar. priority (int): Prioridade, inteiro não negativo. status (MissionStatus): Estado atual; começa em PROPOSED.

def change_status(self, new_status: MissionStatus):

Devolver uma nova missão com o estado atualizado, se a transição for válida.

Transições permitidas: PROPOSED → RESERVED → RUNNING → DONE ou FAILED.

Args: new_status (MissionStatus): Novo estado pedido.

Returns: Mission: Uma nova instância com o estado atualizado.

Raises: TypeError: Se o novo estado não for um MissionStatus. ValueError: Se a transição não for permitida.
