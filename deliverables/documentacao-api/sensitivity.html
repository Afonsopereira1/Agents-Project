class BlockedExperiment(builtins.ValueError):

Uma alternativa prevista exige alteração de contrato ainda não aprovada.

def encoded(value):

Serializar em JSON canónico: chaves ordenadas, sem espaços, Unicode literal.

Args: value (object): Valor serializável em JSON.

Returns: str: Texto JSON, estável entre execuções (serve de chave e de coluna valor).

def alternative_matches(value, candidate):

Dizer se um valor alternativo corresponde ao pedido.

Números comparam-se por valor (2 e 2.0 equivalem; NaN e infinitos nunca); listas, elemento a elemento. JSON booleano/null nunca equivale a um número.

Args: value (object): Valor pedido ou lido (ex.: de --value ou de um relatório). candidate (object): Alternativa prevista em PARAMETERS.

Returns: bool: True se os dois representarem a mesma alternativa.

def apply_experiment(config, parameter, value):

Devolver cópias independentes (cenário, opções do runner) de um só fator.

Args: config (dict): Cenário original, que não é alterado. parameter (str): Fator experimental (chave de PARAMETERS). value (object): Alternativa a aplicar; tem de ser uma das previstas.

Returns: tuple[dict, dict]: O cenário com o fator aplicado e as opções extra do runner.

Raises: ValueError: Se o parâmetro for desconhecido, a alternativa não estiver prevista ou a configuração resultante for inválida (ver validate_configuration). BlockedExperiment: Para source_diversity=1, que exige aprovação explícita.

def validate_configuration(config, options):

Validar cenário e opções do runner antes de simular; levanta erro se inválidos.

Além do esquema do cenário, constrói a política e a reputação e passa cada episódio por scenario_settings, para que os erros surjam antes da recolha.

Args: config (dict): Cenário completo (com base_seed, response_settings e episodes). options (dict): Opções extra do runner.

Raises: ValueError: Se base_seed não for inteiro, ou se o cenário, a política, a reputação ou as opções forem rejeitados pelos validadores.

def compare_rows(actual, expected, *, identity):

Comparar todos os indicadores comuns; N/A e arredondamentos são explícitos.

A referência (expected) define os campos comparados; campos extra em actual são ignorados. Números comparam-se com tolerância de 1e-10.

Args: actual (list[dict]): Linhas obtidas. expected (list[dict]): Linhas de referência. identity (tuple[str, ...]): Campos que identificam cada linha nos dois lados.

Returns: list[dict]: Uma diferença por campo divergente ou linha em falta, com identity, field, actual e expected; vazia se coincidirem.

Raises: ValueError: Se uma identidade se repetir em qualquer dos lados.

def read_csv(path):

Ler um CSV UTF-8 como lista de dicionários, com todos os valores em texto.

Args: path (Path): Ficheiro a ler.

Returns: list[dict[str, str]]: Uma entrada por linha, pelas colunas do cabeçalho.

def write_json(path, value):

Gravar JSON indentado num ficheiro novo; falha se já existir ou houver NaN.

Valores não serializáveis são gravados com str.

Args: path (Path): Ficheiro a criar. value (object): Conteúdo a gravar.

def write_csv(path, rows):

Gravar as linhas num CSV novo, com None como "N/A".

As colunas são a união dos campos, pela ordem em que aparecem. Sem linhas não cria ficheiro; falha se o ficheiro já existir.

Args: path (Path): Ficheiro a criar. rows (list[dict]): Linhas a gravar.

def create_output(run_id=None):

Criar a pasta de saída da recolha.

A raiz de escrita é fixa e o mkdir exclusivo impede substituir recolhas.

Args: run_id (str | None): Nome da pasta em results/sensitivity/; None gera um a partir da data UTC e de um sufixo aleatório.

Returns: Path: A pasta criada.

Raises: ValueError: Se run_id não for um nome simples ou se a raiz de resultados for um atalho para outro diretório.

def provenance():

Descrever o código e o ambiente usados na recolha.

Inclui commit, ramo, alterações sem commit, versões de Python e SPADE, plataforma e SHA-256 das fontes, cenários, requirements.txt e ficheiros de referência.

Returns: dict: commit, branch, dirty, git_status, python, platform, spade, sha256 (por ficheiro: fontes src, este script, config/**/*.json e requirements.txt) e reference_sha256.

async def self_check(mode, configs, output):

Comparar a referência por execução e, no modo completo, por agregado.

No modo initial corre só a primeira repetição do cenário A e compara-a com runs.csv; no full corre os cenários todos e compara execuções, ordem e resumo. Grava actual.csv (e actual-runs.csv) e comparison.json em output.

Args: mode (str): "initial" ou "full". configs (list[dict]): Cenários a correr; ignorado no modo initial. output (Path): Pasta do self-check.

Returns: dict: Resultado com passed, run_count, differences e, no modo full, as comparações por execução e por resumo.

Raises: ValueError: Se a referência gravada não tiver as sementes, episódios ou ordem da Etapa 9.

def plan_experiments(configs, parameters, value=<object object>, repetitions=None):

Construir o plano: um item por parâmetro, alternativa e cenário.

Cada item traz a configuração aplicada, ou o estado blocked/invalid com o motivo, e as repetições, sementes e episódios previstos.

Args: configs (list[dict]): Cenários originais. parameters (list[str]): Fatores a incluir. value (object): Restringe o plano a uma alternativa; UNSET inclui todas. repetitions (int | None): Repetições por cenário; None usa as do cenário.

Returns: list[dict]: Itens com parametro, valor, cenario, status, repetitions, seeds, episodes, runs e ainda config e runner_options (se ready) ou reason (se não).

Raises: ValueError: Se nenhuma alternativa corresponder a value.

def report_extras(records):

Somar os indicadores extra de um grupo de relatórios sobre as execuções.

Execuções expiradas, contagens por motivo final, recusas por autonomia, missões e CFP de rangers e atualizações de reputação.

Args: records (list[dict]): Ficheiros de relatório, com a chave report.

Returns: dict: expired_runs, reason_<motivo> para quatro motivos, autonomy_insufficient, ranger_missions_known, ranger_cfp_sent e reputation_updates.

async def collect(plan, configs, repetitions, output):

Correr a referência e cada alternativa pronta do plano e gravar os CSV do lote.

Escreve runs.csv, summary.csv e as tabelas de calibração, e etiqueta cada relatório individual com o fator.

Args: plan (list[dict]): Plano de plan_experiments; itens que não estão ready são saltados. configs (list[dict]): Cenários originais, para as referências. repetitions (int | None): Repetições por cenário; None usa as do cenário. output (Path): Pasta do lote.

Returns: int: Número total de execuções (referência e alternativas).

def main(argv=None):

Validar a seleção, correr o self-check e depois as alternativas.

Depois de gravado o plano e copiado o código, manifest.json é gravado mesmo em caso de falha. Erros de seleção ou de dados antes de criada a pasta de saída terminam via parser.error.

Args: argv (list[str] | None): Argumentos da linha de comandos; None usa sys.argv.

Returns: int: 0 em sucesso e 1 se a seleção não for executável ou a referência divergir.
